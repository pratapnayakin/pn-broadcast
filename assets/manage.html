PN Broadcast - Manage feeds

Add or remove feeds from the browser. Changes go through a Pull Request you review and merge.

Step 1 - connect to GitHub

Create a fine-grained token for this repo with Contents: read and write and Pull requests: read and write. The token stays in this browser only and is sent only to api.github.com.

Step 2 - add a feed

Each line becomes a quoted phrase. No URL encoding needed.

A new section is created on the site, with its own archive page and tab.

Use this when a source is broad but you want one place only. Comma separated.

How the pull request works
  1. The page reads feeds.json from your repo.
  2. Your change is applied to a copy in the browser.
  3. A new branch is created with the change and a pull request is opened.
  4. You review the diff on GitHub and tap Merge.
  5. The next refresh, within 30 minutes, picks it up.

Nothing is written to your repo until you merge the pull request.
